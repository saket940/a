# InternHub (React + Express + npm)

This repository is set up as an **npm workspace** with:

- `artifacts/internhub`: React + Vite frontend
- `artifacts/api-server`: Express backend

## Getting started

```bash
npm install
npm run dev
```

## Useful scripts

```bash
npm run dev          # run React and Express together
npm run dev:client   # run the React app only
npm run dev:server   # run the Express API only
npm run build        # build the frontend and backend
npm run typecheck    # run TypeScript checks
```
